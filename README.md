# ProjetWeb — Plateforme de recherche de stages

Application web permettant de centraliser des **offres de stage** et des **entreprises**, avec gestion des **rôles** (Administrateur, Pilote, Étudiant, Anonyme), candidatures et wish-list.

---

## 🎯 Objectifs

- Faciliter la recherche de stage des étudiants
- Centraliser les offres et les entreprises partenaires
- Permettre le suivi des candidatures (étudiant / pilote)
- Mettre en place un site **responsive**, **sécurisé**, et conforme aux bonnes pratiques (SEO, mentions légales)
